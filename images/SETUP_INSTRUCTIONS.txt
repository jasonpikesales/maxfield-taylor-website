MAXFIELD TAYLOR WEBSITE - LOCAL SETUP INSTRUCTIONS
===================================================

To see the website with all images working, follow these steps:

STEP 1: CREATE FOLDER STRUCTURE
================================
On your Mac, create a new folder called "Maxfield-Taylor-Website" (anywhere is fine - Desktop, Documents, etc.)

Inside that folder, create a subfolder called "images"

Your structure should look like:
Maxfield-Taylor-Website/
├── maxfield-taylor.html
└── images/
    ├── (all image files go here)

STEP 2: ADD THE HTML FILE
==========================
1. Download maxfield-taylor.html from this conversation
2. Move it into the "Maxfield-Taylor-Website" folder (NOT into the images subfolder)

STEP 3: ADD THE IMAGES
======================
Copy these image files into the "images" subfolder:

You can find these images in the Claude outputs folder or the original uploads.

STEP 4: OPEN IN BROWSER
=======================
1. Open Finder
2. Navigate to your "Maxfield-Taylor-Website" folder
3. Double-click "maxfield-taylor.html"
4. Your browser will open and display the website with all images!

STEP 5: NAVIGATE THE SITE
=========================
- Click "Collections" to see all 8 product lines
- Click any product card to see its full page
- Click "Get in Touch" to see the contact page
- Use back buttons to navigate

That's it! You now have a fully working mockup of your website.

NOTES:
======
- This is a standalone HTML file that works on your local computer
- No internet connection needed
- All navigation and links work
- Images display locally
- When you're ready to go live, you'll upload this file + the images folder to a web host

NEXT STEPS FOR GOING LIVE:
==========================
1. Register maxfieldtaylor.com domain
2. Set up maxfieldtaylor.com email
3. Upload HTML + images to web hosting (Netlify or Vercel recommended)
4. Set up Formspree for contact form submissions
5. You're live!
